# RT Lab Unified Medical & Financial ERP (منظومة معامل RT الطبية والمالية الموحدة)

منظومة موحدة متكاملة وشاملة لمعامل RT للتحاليل الطبية والتشخيصية (معامل رامي مختار - أطباء كلية طب قصر العيني).
تجمع النظام المالي ونظام التشخيص والنتائج في نظام واحد متكامل بدون حقول مكررة وبدون تعارض.

## المميزات الرئيسية للمنظومة الموحدة:
1. **تسجيل المرضى وحجز التحاليل**: شاشة استقبال موحدة للمريض، توليد أرقام التحاليل والباركود تلقائياً.
2. **الربط المالي والفوري**: إصدار فواتير الدفع، خصومات التأمين والنقابات، وإيصالات استلام رسمية بنظام تفقيط المبالغ بالعربية.
3. **كروت ونقاط الولاء (Loyalty Program)**: حساب نسب الخصم ونقاط الزيارات لكل مريض آلياً ومتابعة رصيده.
4. **الربط مع أجهزة المعمل (LIS Hardware Integration)**:
   - جهاز صورة الدم الكاملة Mindray BC-5380 (5-Part Auto Hematology Analyzer).
   - جهاز الكيمياء Mindray BS-240 / BS-200 (Clinical Chemistry Analyzer).
   - قراءة ASTM / HL7 ونقل النتائج مباشرة إلى تقرير المريض.
5. **محرر التقارير والتشخيص الطبي**:
   - أكثر من 100 تحليل مخبري معتمد مع القوالب والمدى المرجعي الدقيق بحسب العمر والجنس.
   - صور وتشخيصات توضيحية للأمراض الدموية والكيميائية (Clinical Pathology Illustrations).
   - طباعة تقارير A4 احترافية، علامة مائية، كود QR للتحقق، وتوقيعات الأطباء المعتمدة.
6. **لوحة تحكم مركزية للإدارة (Admin Executive Dashboard)**:
   - متابعة الإيراد اللحظي وعينات اليوم.
   - مراقبة الأرباح والمصروفات (P&L).
   - رصد المخزون ونواقص المحاليل.
7. **أمان البيانات الطبية والخصوصية**:
   - صلاحيات دقيقة حسب الدور (طبيب معمل، كيميائي، موظف استقبال، محاسب، مدير عام).
   - سجل تدقيق كامل للعمليات (Audit Log) مع إمكانية التصدير والاستيراد المشفر للبيانات.
